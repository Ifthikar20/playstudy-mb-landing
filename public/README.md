# Static assets

Anything in this folder is served from the site root at runtime.

## Required assets

| File path                       | What it is                                          |
| ------------------------------- | --------------------------------------------------- |
| `public/main-logo.png`          | PlayStudy logo (shown in the nav + footer)          |
| `public/videos/watercolor-.mp4` | Background video that plays inside the CTA card     |

Drop your real files at these exact paths. The included `main-logo.png` is a
1×1 transparent placeholder so the build resolves; replace it.

To copy from your Mac:

```bash
cp "/Users/ifthikaraliseyed/Downloads/MOBILE APP PS/playstudy-mb-landing/main-logo.png" public/main-logo.png
cp "/Users/ifthikaraliseyed/Downloads/MOBILE APP PS/playstudy-mb-landing/watercolor-.mp4" public/videos/watercolor-.mp4
```
